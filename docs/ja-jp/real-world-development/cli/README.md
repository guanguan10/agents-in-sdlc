**[GitHub Copilot CLI][about-copilot-cli]** を使うと、ターミナルで GitHub Copilot をエージェント型のコーディング アシスタントとして利用できます。コードベースを調べ、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから実行できるため、グラフィカル エディターに切り替えず作業に集中できます。

このワークショップでは、Tailspin Toys を使った一連のワークフローを進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、基本を確認します。
2. 星評価を変更し、ブラウザーでレビューして、最初のプルリクエスト (PR) を手動でマージします。
3. フィルター機能の Issue から始め、Plan モードでアプローチを定め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズして、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルターの動作を調べます。
7. 品質保証 (QA) カスタム エージェントを作成し、要件、テスト範囲、検証の証拠をレビューします。
8. フィルター機能の変更全体をレビューし、フィルターの PR に Agent Merge を使用します。
9. コンテキスト、モデル、共有、任意のクラウド委任に便利なスラッシュ コマンドを確認します。

このワークショップでは、星評価用とフィルター用の 2 つの PR を作成します。フィルター用 PR には、指示、スキル、QA プロファイル、テストの更新が含まれます。フィルターと品質のワークフローでは、1 つの会話とブランチを共有するため、各ツールを学びながら作業を積み重ねられます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランが設定された GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していませんか。認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
